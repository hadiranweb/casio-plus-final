# Casioplus Studio

این package سطح ساخت و حکمرانی Casioplus است و در `studio.casioplus.com` ارائه می‌شود. مسئولیت‌های آن شامل Flow registry، builder، input/output schema، runtime binding، policy، test run، versioning، publication، Agent configuration و Memory governance است.

Studio مستقیماً به PostgreSQL، n8n UI، OpenClaw Gateway یا credential خام متصل نمی‌شود. Core/API تنها مرجع ثبت Flow، FlowVersion، ProcessRun، Review و Memory است.
